# Facial recognition for access control in a constrained environment.

<Figure
  src="/projects/kkbsecu-hero.png"

BkSquare wanted to reinforce access to a room containing sensitive
computing equipment, without installing heavy infrastructure. I
designed a facial-authentication system that runs on a modest fixed
workstation, with a standard HD camera, and **logs every attempt**
locally and to Firebase.

The pipeline was implemented in Python with OpenCV for acquisition
and detection, a recognition model trained on an internal sample,
and an operator UI in CustomTkinter. Software modelling followed
the **2TUP** process, supported by UML diagrams — that's what let
me keep the code readable despite the rapid iterations the company
was asking for.

<Figure
  ratio="inline"

</Figure>

The system was defended as an end-of-degree thesis, **rated 19/20
and named best defence project**. It's now in internal use at
BkSquare, and I was hired at the end of the internship.

<Callout kind="insight" label="What I take from it">
Constraining the hardware forces the model to stay honest. A standard HD camera and a modest workstation impose choices (resolution, batching, framerate) that, made upfront, also improve code readability.
</Callout>
