# Rethinking a school's online presence.

<Figure
  src="/projects/site-ecole-hero.png"

This prototype came out of my web development learning. I took a
real institution, IUSTE, as a case study to work on a concrete need:
presenting the school clearly and letting prospective students
pre-register online.

I built the whole prototype: **wireframes, visual identity, a
responsive interface in HTML, CSS and JavaScript**, then a
pre-registration module in **PHP and MySQL** to record and process
applications. The server side is deliberately simple, so it stays
easy to maintain.
