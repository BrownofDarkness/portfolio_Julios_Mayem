# Find a nearby restaurant, filtered by what you actually want.

AfriDelight (developed under the project name Delicio Food) started
from a plain observation: search apps don't help you choose between
ten equivalent suggestions. What was missing was a fast filter and a
map that updates as soon as the user changes a criterion.

I built this prototype with **Flutter and Dart**. I integrated Google
Maps and GPS geolocation, then set up **SQLite** persistence for
favourites and history, so the app stays usable on an unstable
network.
